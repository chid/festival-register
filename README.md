# Sydney, Melbourne & Canberra Festival Register

Searchable register of recurring festivals, with price tiers and 2024/2025 past editions.
Compiled with AI assistance (Claude Haiku/Sonnet) from web searches; **unverified, check official sites before planning**.

Price tiers (AUD, cheapest typical paid entry): Free, Low (<$30), Mid ($30-100), Premium (>$100).

Add or correct an entry: open a [submission issue](../../issues/new?template=submit-festival.yml).
Data lives in `data.json`.
